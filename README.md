# Smart Study Buddy

Smart Study Buddy is an AI-powered learning assistant that helps students understand topics faster.

Features:
- AI-generated study summaries
- Key point extraction
- Quiz question generation
- Concept explainer (ELI5)
- Learning progress dashboard

Tech Stack:
Backend: Python, Flask
AI Models: Hugging Face Transformers, Groq Llama
Frontend: HTML, Bootstrap, Chart.js
